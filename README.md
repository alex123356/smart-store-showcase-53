# Smart Store Showcase (53)

Build a simple, modern, premium Arabic RTL website for a small Libyan computer accessories business called “المتجر الذكي”.

This is a business showcase website, NOT an e-commerce website.

The website should be simple, clean, modern, interactive and fast on mobile.

Do not overcomplicate it.

⸻

1. LANGUAGE

The website must be Arabic-first.

Use:

lang="ar"

and:

dir="rtl"

All visible text must be natural Arabic suitable for a small Libyan business.

Do not use Lorem Ipsum.

Do not use emojis.

Do not use unnecessary English text.

⸻

2. EXACT COLOR PALETTE

Use this exact palette:

* Main dark: #111827
* Main blue: #2563EB
* Light blue: #DBEAFE
* Main background: #F8FAFC
* White: #FFFFFF
* Secondary text: #64748B
* Border: #E2E8F0

Color usage:

* #F8FAFC for the main page background.
* #FFFFFF for cards and navigation surfaces.
* #111827 for main headings and important text.
* #64748B for secondary text.
* #2563EB for primary buttons, links, highlights and interactive elements.
* #DBEAFE for very subtle blue backgrounds, highlights and decorative areas.
* #E2E8F0 for borders.

Do not introduce random colors.

Do not use excessive gradients.

If a gradient is used, keep it extremely subtle and use only the existing blue palette.

⸻

3. BRAND / LOGO

The navigation must contain:

1. A separate logo.
2. The business name next to it.

The logo and business name must be completely independent.

Changing the business name must NOT change the logo.

Changing the logo must NOT change the business name.

For now, create a simple temporary technology logo inspired by a game controller / computer controller, using the existing blue palette.

Do NOT use an emoji as the logo.

Create the logo as a simple clean SVG-style mark.

Make the logo easy to replace later with the real client’s logo.

Example:

[Controller-style logo] المتجر الذكي

⸻

4. NAVIGATION

Create a clean modern navigation bar.

Desktop navigation:

Logo + business name on one side.

Links:

الرئيسية
من نحن
ما نقدمه
تواصل معنا

Primary button:

تواصل معنا

The navigation should be clean and minimal.

On mobile, use a simple hamburger menu.

The mobile navigation must be easy to use with one hand.

⸻

5. HERO

Create a large but simple modern hero section.

The hero should immediately explain the business.

Use this main heading:

كل ما تحتاجه لحاسوبك، في مكان واحد.

Use a short supporting sentence:

كماليات وإكسسوارات الحاسب بتجربة بسيطة وسهلة.

Primary button:

تواصل معنا

Secondary button:

تعرف علينا

Keep the text short.

Do not fill the hero with information.

⸻

6. HERO VISUAL

Place a large modern technology visual beside the hero text on desktop.

Use a clean visual inspired by a:

* game controller
* computer accessory
* laptop accessory
* modern technology device

The visual should look premium and modern.

Keep it simple.

Do not create a complicated futuristic scene.

The visual should be easy to replace later with a real product image.

⸻

7. HERO ANIMATION

Add subtle modern animation.

The animation should make the website feel alive without making it heavy.

Use lightweight CSS animations.

The hero should have:

* Smooth entrance animation for the text.
* Smooth entrance animation for the main visual.
* Very subtle floating movement on the technology visual.
* Small hover effect on buttons.
* Very subtle movement on decorative elements.

Do NOT use:

* Three.js
* WebGL
* particles
* heavy canvas animations
* large background videos
* autoplay videos
* complicated 3D systems
* heavy parallax

The animation must remain smooth on mobile.

Prioritize performance over visual effects.

⸻

8. MOBILE HERO

On mobile, do not simply shrink the desktop layout.

Change the hero into a clean vertical layout:

1. Heading
2. Description
3. Buttons
4. Technology visual

The visual should appear below the text.

Make everything fit comfortably on small screens.

Support approximately:

320px, 360px, 390px and 430px wide screens.

Do not allow horizontal scrolling.

Do not allow the visual to cover text.

Do not make the heading excessively large.

⸻

9. ABOUT SECTION

Create a simple section titled:

من نحن

Use a short natural Arabic paragraph explaining that المتجر الذكي is a local business focused on computer accessories and related products.

Keep this section short.

Do not invent years of experience, awards, certifications or statistics.

⸻

10. WHAT WE OFFER

Create a simple section titled:

ما نقدمه

Keep it focused on computer accessories and related products.

Use only a few simple categories:

* كماليات الحاسب
* إكسسوارات الكمبيوتر
* ملحقات الألعاب
* مستلزمات الكمبيوتر

Use clean cards.

Each card should have:

* simple icon
* title
* one short description

Add a subtle hover effect on desktop and a subtle press effect on mobile.

Do not add services such as:

* camera installation
* networking
* security systems
* maintenance
* unrelated technical services

This is a simple computer-accessories business website.

⸻

11. PRODUCT / VISUAL AREA

Add a simple visual section showing attractive computer accessories or technology products.

This is only for presentation.

This is NOT an online shop.

Do NOT add:

* shopping cart
* checkout
* payment system
* product accounts
* product filtering
* product prices
* inventory
* complicated product database

The images must be easy to replace later.

Use optimized image placeholders if real images are not available.

⸻

12. CONTACT

Create a clean section titled:

تواصل معنا

Show:

* WhatsApp
* Phone
* Facebook
* Location

Create real clickable links.

WhatsApp should use a wa.me link.

Phone should use a tel: link.

Facebook should use a normal Facebook URL.

Location should open a map.

Use clearly marked editable placeholders for the real contact details.

Do not create fake forms.

⸻

13. FOOTER

Create a small clean footer.

Include:

* Logo
* Business name
* Short description
* Contact links
* Social links
* Copyright

Keep it simple.

Do not make a huge footer.

⸻

14. RESPONSIVE DESIGN

The website must be mobile-first.

It must look good on:

* mobile
* tablet
* laptop
* desktop

Test the layout mentally and structurally at:

320px
360px
390px
430px
768px
1024px
1440px

Make sure:

* no horizontal scrolling
* no broken text
* no oversized elements
* no overlapping elements
* buttons are easy to tap
* navigation works
* images scale correctly
* Arabic RTL alignment is correct

⸻

15. PERFORMANCE

The website must be lightweight.

It should work smoothly on older iPhones and lower-end Android phones.

Prefer CSS animations.

Use:

* transform
* opacity
* lightweight transitions
* optimized images
* lazy loading

Avoid unnecessary JavaScript.

Do not use heavy animation libraries.

Do not use WebGL or Three.js.

Do not use large video backgrounds.

The website should feel fast.

⸻

16. ANIMATION RULE

The website should feel modern because of subtle motion, not because of excessive effects.

Animations should be short, smooth and useful.

Respect:

prefers-reduced-motion

When reduced motion is enabled, disable or reduce non-essential animations.

⸻

17. EDITABLE BUSINESS INFORMATION

Keep these items easy to replace later:

Business name:
المتجر الذكي

Logo:
Separate from business name.

Phone:
PLACEHOLDER_PHONE

WhatsApp:
PLACEHOLDER_WHATSAPP

Facebook:
PLACEHOLDER_FACEBOOK

Address:
PLACEHOLDER_ADDRESS

Map:
PLACEHOLDER_MAP_URL

Hero image:
Separate replaceable image.

Product images:
Separate replaceable images.

Make sure replacing any of these does not require rebuilding the website.

⸻

18. IMPORTANT DESIGN RULES

Keep the entire website simple.

Do not add unnecessary sections.

Do not add unnecessary features.

Do not make it look like an online store.

Do not make it look like a SaaS website.

Do not make it look like a corporate enterprise website.

Do not use cyberpunk styling.

Do not use excessive neon.

Do not use excessive glassmorphism.

Do not use excessive rounded cards.

Do not use excessive gradients.

Do not use emojis.

Do not invent business information.

Do not create fake reviews.

Do not create fake statistics.

Do not create fake certifications.

The final website should feel like a real, modern, trustworthy small Libyan computer-accessories business.

⸻

19. FINAL CHECK

Before finishing, make sure:

* Arabic RTL works correctly.
* Mobile layout is excellent.
* Desktop layout is clean.
* Logo is independent from business name.
* Logo is easy to replace.
* Business name is easy to replace.
* Hero visual is easy to replace.
* WhatsApp button works.
* Phone button works.
* Facebook link works.
* Map link works.
* Navigation works.
* Mobile menu works.
* No horizontal scrolling exists.
* Animations are lightweight.
* Website loads quickly.
* No unnecessary features were added.
* No fake information was added.
* No emojis were used.

Build the complete website now.

Keep the implementation simple, clean, maintainable and easy to edit later.
